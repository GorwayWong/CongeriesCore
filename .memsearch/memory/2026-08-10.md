## 我理解的 docs 架构

`docs/` 描述的是一套微内核式 Agent Runtime：

- Application Plugins 提供业务 Workflow、Skill、Tool、Provider、MCP 能力。
- Core Runtime 负责 Agent 和 Workflow 执行。
- Harness 提供生命周期、上下文、记忆协议、审批、评估和恢复能力。
- Workspace 保存长期执行状态。
- Runtime Events 提供 tracing 和可观测性。
- 外部框架、LLM、数据库通过 Provider/Adapter 接入。
- Core 不拥有业务模型、记忆实现或具体数据库。
