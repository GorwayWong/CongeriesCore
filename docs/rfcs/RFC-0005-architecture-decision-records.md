# RFC-0005: Legacy Architecture Decision Record Bundle

- ID: RFC-0005
- Title: Legacy Architecture Decision Record Bundle
- Status: Withdrawn/Misclassified
- Target Version: 0.2.0
- Owner: CongeriesCore Maintainers
- Created: 2026-08-10
- Updated: 2026-08-10
- Related: [ADR Registry](../adrs/README.md), [Documentation Registry](../README.md)
- Supersedes: None

## Disposition

RFC-0005 incorrectly bundled architecture decision records under an RFC
identifier. It contains no normative v0.2 contract.

Its decisions were migrated without changing their meaning:

- ADR-0001: Workflow engines are adapters.
- ADR-0002: Memory is provided by plugins.
- ADR-0003: Runtime Events are not Event Sourcing.
- ADR-0004: Workflow is first-class.
- ADR-0005: External capability is interface-first.

Use the [ADR Registry](../adrs/README.md) for current records. RFC-0005 remains
reserved and must not be reused.
